# 迷宮評量：搖桿目標位置與攝影機 PID

這是獨立的迷宮韌體。攝影機辨識球，Nano 以 PID／PD 控制 Servo；搖桿改變**目標位置**，不直接控制 Servo，也不改變平台座標原點。推住搖桿時目標沿該方向移動，鬆開後停在目前目標。攝影機畫面以紫色十字顯示目標，終端機的 `JOYSTICK: armed.` 表示搖桿已啟用。

## 接線

接線變更前先斷電。Servo 使用符合規格、電流足夠的獨立 5–6 V 電源，電源 GND 與 Nano GND 共地；不要由 Nano 5 V 腳供應 Servo。

| Nano | 接到 | 用途 |
| --- | --- | --- |
| A0 | 搖桿 VRx | X 目標 |
| A1 | 搖桿 VRy | Y 目標 |
| 5V | 搖桿 VCC | 搖桿供電 |
| GND | 搖桿 GND、Servo 電源 GND | 共地 |
| D9 / D10 | Servo X / Y 訊號線 | 控制平台 |
| USB | 電腦 | 燒錄與攝影機資料 |

此韌體不使用搖桿按鈕 SW。**不可把搖桿拔除或讓 A0/A1 懸空後使用此版本**，浮動輸入可能讓目標自行移動。

## 設定與燒錄

1. 先用原有機構校正程式完成中立角、方向、安全行程，再用正式 PID 程式測試攝影機和控制方向。校正與調參尚未完成時，先不要將迷宮版用於正式評量。
2. 用 Arduino IDE 開啟本資料夾的 `Arduino_Nano_Ball_Balance_Maze.ino`。目前程式的中心、行程、方向、PID 參數為：X 中心 77°、Y 中心 87°、行程各 ±20°、X/Y 方向均為 -1、兩軸 Kp=1.25、Ki=0、Kd=0.5。**這些只是當時的程式值，不代表實機已校正或調好。**
3. 每次校正或調參有更新，都要把正式韌體中對應的 `SERVO_X_CENTER`、`SERVO_Y_CENTER`、`SERVO_LIMIT_OFFSET_DEG`、`SERVO_X_DIRECTION`、`SERVO_Y_DIRECTION`、`DEFAULT_KP/KI/KD_X/Y` 值手動同步到迷宮韌體；兩個檔案不會自動同步。確認安全端點不會碰撞、中心角與端點在 Servo 可動範圍內。
4. 上傳迷宮韌體到 Nano，關閉 Arduino Serial Monitor，再啟動 `Camera_Vision/start_camera_vision.sh`。Camera Vision 也需使用本專案更新後的版本才會顯示目標。
5. 第一次先在**沒有迷宮與洞口、球不易掉落**的情況下測試，從小位移開始。確認安全與兩軸方向後，再放上迷宮。迷宮牆壁與洞口不得遮住球和攝影機校正角點；如果球在洞中或被遮蔽後辨識不到，系統將停機。

## 操作

1. 固定攝影機、依原 Camera Vision 操作做 B（球色）與 C（平台四角）校正。更換迷宮、移動攝影機或平台後，重新確認四角、球的橘色 CONTACT 點和偵測是否可靠。
2. 球放在安全區域，將搖桿保持中立，按 `R` 啟動。目標初始為球的目前位置；若球已在目標允許範圍之外，目標會限制到允許範圍內，可能造成球移動。開始時請把球放在平台中央附近。
3. 每次啟動後都要先讓搖桿回到中立區，看到終端機的 `JOYSTICK: armed.` 才能操作；若顯示 `JOYSTICK: release to neutral to arm.`，先放開搖桿。推動搖桿移動目標，鬆開後目標保持。
4. 如目標移動方向相反，可按 `P` 停止，修改韌體的 `JOYSTICK_X_DIRECTION` 或 `JOYSTICK_Y_DIRECTION` 為 `-1`，重新燒錄；先確認紫色目標移動方向，再檢查球的實際反應。
5. 按 `P` 停止並回 READY；每次重新 RUN，目標會重新設為當下球位置、搖桿需要再次回中立。辨識不到球、位置逾時約 300 ms 或資料超界時，Nano 會停止控制並回 Servo 中立；平台不一定因此維持水平，仍須看顧球及機構。

## 調整目標操作手感

在韌體頂端設定並重新燒錄：

- `JOYSTICK_CENTER_X/Y`：中立類比讀值，預設 512；中立偏差大時可用校正程式的 `JOY` 量測後修改。
- `JOYSTICK_DEADZONE`：中立死區，預設 100；鬆開後目標漂移時可在確認接線後適度增加。
- `TARGET_SPEED_PCT_PER_SECOND`：最大目標速度，預設每秒 20 個座標百分點；降低可使操作較慢。
- `TARGET_RANGE_FRACTION`：目標相對中心到邊緣的最大比例，預設 0.8，即標準座標限制在 X/Y 各 −80 至 +80。這只限制目標，不保證球不會越界、撞牆或落入洞口；也可能使靠近邊緣的路線無法抵達。修改前須確認安全行程及迷宮設計。

座標 X 正方向為畫面右方，Y 正方向為平台上方／遠端。搖桿硬體方向因模組與安裝方向不同，需實測設定。D 項根據球的移動計算，避免目標移動直接造成 D 項突跳；其效果仍需實機調參。

## 評量建議

先共同固定起始點、洞口、操作時間、球與迷宮配置及計分方式。若採「離洞口最遠」：時間到後記錄球中心至指定洞口中心的距離；落洞、無法辨識、觸碰球等情況的處置與同分規則，賽前由教師公布。距離可用實體尺或事先確認過比例的相機測量；目前程式**沒有自動計時、偵測洞口或計分**。此項可作為課程評量的一部分，另搭配校正、參數比較紀錄及個人說明。

## 本機測試

`tests/run.sh` 用桌面 C++ 模擬時間、搖桿、序列命令及 Servo，測試目標移動、啟動中立、防超範圍、D 項與失聯停機；不是 Arduino 實板或實機測試。
